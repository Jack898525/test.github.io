1. 纯净的 Content (内容)

我是玻璃杯 (宽200 高100)
没有气泡膜，没有纸箱

2. Content + Padding (内边距)

我是包了气泡膜的玻璃杯
我的设定还是宽200，但加上Padding，我被撑大了！

3. Content + Padding + Border (边框)

我被装进红色的纸箱啦！
外面多了一圈实线外壳。

4. Content + Padding + Border + Margin (外边距)

我是一个完整的快递箱！
我有 Margin，所以我强制要求周围50px内不能有其他东西。
我是隔壁的黑色小箱子，我被紫色的箱子（通过Margin）推开了！
